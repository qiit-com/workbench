# 暮色 Dusk · 个人工作台

一个纯本地的个人工作台 PWA：待办 · 专注 · 选题库 · 读书 · 播客 · 运动 · 饮食。从暖橙暮色渐入青灰夜色的玻璃拟态设计，因此得名「暮色」。

无后端、无账号、无云同步——所有数据存在你自己设备的 IndexedDB 里，支持一键导出 / 导入迁移。

在线预览：**https://workbench.qiit.com/dusk/app/**
详情页：https://workbench.qiit.com/dusk/ · 工作台合集：https://workbench.qiit.com

## 特性

- **待办**：今日视图 + 逾期堆叠 + 月历三态圆点 + 未排期常驻；模块生成的待办带来源色条并可回链
- **专注**：25 分钟一轮的环形倒计时，时长自动累计到对应待办
- **选题库**：想法 → 进行中 → 已发布自动流转；四个制作阶段一键生成排期待办
- **读书**：在线书目搜索入库、半星评分、按时长生成阅读待办
- **播客**：Apple Podcasts 数据源、应用内播放（倍速 / ±10 秒 / 进度记忆）、带时间戳的笔记
- **运动**：月历打卡三态点、固定类型清单、力量训练三列滚轮录入 + 动作库
- **饮食**：三餐固定占位、照片、饭量三档
- **天气**：定位（HTTPS 下弹授权）→ 失败自动退回 IP 归属地；含农历
- **PWA**：可安装到主屏幕、离线可用

## 技术

原生 HTML / CSS / JavaScript，**零依赖、零构建**。IndexedDB 持久化，Service Worker 离线缓存。

外部数据源（均为免费公开接口）：Open-Meteo（天气/地理编码）、myip.ipip.net / ipapi.co（IP 归属地）、Google Books / OpenLibrary（书目）、iTunes Search API（播客）。

## 数据与隐私

全部数据只存在浏览器本地（IndexedDB），不上传任何服务器。换设备前用 设置 → 导出 生成 JSON 备份（含照片），新设备上 设置 → 导入 即可。

## 🤖 AI 提示词

想让你自己的 AI 写一个类似的应用？复制下面这段提示词直接用：

```text
帮我做一个叫「个人工作台」的 PWA 应用：纯前端、无后端、无账号，
原生 HTML/CSS/JS 零依赖零构建，数据全部用 IndexedDB 持久化在本机，
manifest + Service Worker 支持安装到主屏幕和离线使用，移动端竖屏优先。
视觉风格：暖橙到青灰的对角渐变背景 + 玻璃拟态半透明卡片（大圆角、背景模糊）。

模块需求：
1. 首页：按时段的问候语；天气日期卡（定位取天气，拿不到定位就用 IP 归属地兜底，
   显示农历；点卡片进入全部待办）；今日待办列表（标题行右侧细进度条 n/m，
   点卡片展开备注和「进入专注/推迟到明天/编辑」，点右侧圆圈勾选完成）；
   下方「逾期未完成」段按逾期天数从近到远排，勾完成即从该段消失；
   底部常驻「新建待办」；左上汉堡抽屉导航到各模块，每项带一条真实数据小字。
2. 待办：月历视图，格子下圆点三态（有未完成=浅白点、全部完成=绿点、无待办=不显示）；
   日期为空的待办常驻列表下方，带「排期」按钮直达编辑页；
   编辑页=新建页同一张表：标题必填、日期/时间可空、备注，
   模块生成的待办多一行只读「来源」可跳回源条目，删除按钮收在页底；
   专注模式：25 分钟一轮，环形倒计时可暂停/提前结束，
   结束页显示本轮时长+今日累计+今日待办进度+「顺手标记完成」，时长累计进待办。
3. 自媒体选题库：状态只有 想法→进行中→已发布，且自动流转
   （生成待办后自动变进行中；勾完「发布」阶段的待办自动变已发布并给可撤销提示）；
   详情=编辑=新建同一张表、改完即存；字段：标题（唯一必填）、素材与要点（自由文本）、
   参考链接（剪贴板一键贴入、行尾可删）、截图（网格、长按删除）；
   底部「添加待办」区块：四个固定阶段（写脚本/拍摄/剪辑/发布）勾选生成待办，
   日期方案四选一：今天/下周一/依次每天一条/指定某天（仅最后一项展开月网格）；
   已生成后区块变「修改待办」：已完成的行锁定，取消勾选=删除该待办。
4. 读书：搜书入库（调用在线书目 API，不做手动添加）、想读/在读/读完三态筛选；
   评分和一句话总结只在读完时出现，评分支持半星（点星星左半）可留空；
   「添加待办」浮层：时长档 30/45/60 分钟 + 上面的日期方案，生成待办回链这本书。
5. 播客：iTunes Search API 搜节目和单集；订阅节目列表显示未听数
   （未听=总集数−已听完集数）；单集页应用内播放：前后 10 秒、
   0.8/1.0/1.25/1.5/2.0 五档倍速、进度条可点跳转、进度自动保存；
   带时间戳的笔记：点时间戳跳播、点内容编辑、时间戳可 ±5 秒微调；
   「移出想听」时若该集有笔记，弹确认（笔记会一并清空）。
6. 运动：月历圆点三态（绿=练了、白=已安排未到、灰=已过期没做），选中日用深色块；
   类型是固定清单不可自定义：计时类（跑步/骑行/游泳/瑜伽/快走/跳绳，
   前三个可记距离）、球类（羽毛球/篮球/乒乓球/网球，只记时长）、力量训练；
   计时类记时长（默认30分钟）+感受三档；力量训练按部位（胸/背/腿/肩/臂/核心）记动作，
   每个动作一行「重量×次数×组数」，点数值弹三列滚轮（下方显示上次数值），
   动作从预设动作库多选添加，徒手动作显示「自重」；
   未来日期自动存为计划，计划卡当天可一键「完成」转记录，过期的显示「改期」。
7. 饮食：月历（三餐记全=绿点、记一两餐=浅点，加餐不计入）；
   早/中/晚三餐固定占位（没记的显示空态+记录按钮），底部「加一餐」记加餐/夜宵；
   记一餐：吃了什么（必填）+饭量三档（少/正常/偏多，默认正常），
   餐次和时间按当前时刻自动填好可改，照片最多 9 张。
8. 设置：称呼（首页问候语跟着变）、数据导出/导入（JSON 含照片、导入整体覆盖需确认）、
   关于（版本号）。

全局交互约定：
- 删除一律收在编辑页底部，先弹统一确认框（正文只写「删除后无法恢复。」），不做左滑删除
- 所有数值输入用底部滚轮弹层（上方常用值快捷档、下方显示上次数值），不用键盘
- 所有弹层左下角都有「清空/不设」出口
- 搜索都是全屏层、输入停顿 0.8 秒自动搜索，不放搜索按钮
```
